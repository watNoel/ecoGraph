# ecoGraph

**ecoGraph** is an interactive **R Shiny application** for visualizing interactions in ecological networks.

This project was developed as a collaborative course project during the **RaukR 2024 – Advanced R for Bioinformatics** course, by **Fahime, Noel, and Pamela**.

The application uses ecological network data from the **Web of Life** database:  
https://www.web-of-life.es/

The live Shiny app is available here:  
https://fhmohamadnejad.shinyapps.io/EcoWeb/
